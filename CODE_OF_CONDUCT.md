# Code of Conduct

## Our Pledge

We pledge to make participation in this project respectful, focused, and constructive for everyone.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and experience levels.
- Give and receive technical feedback with care.
- Focus criticism on code, design, documentation, and operational risk.
- Protect private information, credentials, and unpublished security details.

## Unacceptable Behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Publicly disclosing security vulnerabilities before maintainers have a chance to respond.
- Repeatedly derailing technical discussions after maintainers redirect the thread.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this code. Maintainers may also temporarily or permanently restrict participation for behavior that makes the project unsafe or unproductive.

## Scope

This code applies in project repositories, issue trackers, pull requests, discussions, and any project-related communication spaces.
